# Clavio for Alfred

Companion workflow for [Clavio](https://clavioapp.com) — AI hands-free dictation that adapts to every app (macOS 14+, Apple Silicon).

## Install

Download **Clavio.alfredworkflow** from the [latest release](https://github.com/Zhingel/alfred-clavio/releases/latest) and double-click it.

## Usage

Type `clavio` in Alfred:

- **Open Clavio** — launches the app, or opens the download page if it isn't installed (free tier: 3,000 polished words/month, no card)
- **Download Clavio** / **Clavio Changelog**
- **Search 28 dictation guides** — voice typing, punctuation commands, dictating into specific apps (Slack, Word, Google Docs, ChatGPT, WhatsApp…), troubleshooting

Everything is self-contained: one bash script filter, no dependencies, nothing to configure.

## About Clavio

Hold a key or say "Hey Clavio," talk in any app, and finished text — cleaned up, punctuated, in the right tone — types itself where your cursor is. Per-app styles, optional auto-send (great for dictating prompts to AI coding agents), 28 dictation languages, on-device voiceprint.
